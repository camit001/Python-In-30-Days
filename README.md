## Goal

The goal is to move beyond memorizing Python syntax and become comfortable using Python for real-world programming, automation, data analysis, web development, database interaction and API development.

By the end of the 30 days, you should be able to read Python code, write programs, work with files and data, interact with databases and APIs, and build a small Python application from scratch.
